Competitive Geometry Reference (1900–2300)

Essential mathematical primitives, coordinate rotations, and lattice theorems

1. Manhattan ↔ Chebyshev Transformation

Transform coordinates via $(x, y) \to (x+y, x-y)$.

$$|x_1 - x_2| + |y_1 - y_2| = \max(|X_1 - X_2|, |Y_1 - Y_2|)$$

Converts diamond $L_1$ metrics into axis-aligned squares, enabling 1D/2D Segment Trees & Sparse Tables.

2. 2D Vector Cross Product & Orientation

For vectors $\vec{u}=(x_1, y_1)$ and $\vec{v}=(x_2, y_2)$:

$$\vec{u} \times \vec{v} = x_1 y_2 - x_2 y_1 = 2 \times \text{Area}(\triangle)$$

$> 0$: Counter-Clockwise (Left Turn); $< 0$: Clockwise (Right Turn); $= 0$: Collinear.

3. Pick's Theorem on Lattice Polygons

Relates polygon area, strictly interior points ($I$), and boundary points ($B$):

$$\text{Area} = I + \frac{B}{2} - 1, \quad B = \sum_{i} \gcd(|\Delta x_i|, |\Delta y_i|)$$

Allows evaluating parity invariants $\pmod 2$ in $O(1)$ by grouping coordinate residues.

4. Angular Sweep Line on Circles

Binary search on radius $R$. Each point within $2R$ defines a valid polar angle interval on circle $C(0, R)$.

$$\alpha = \text{atan2}(y_i, x_i), \quad \Delta = \arccos(d_i / 2R)$$

Split wrap-around intervals at $2\pi$ and find maximum interval overlap using a sweep line.
