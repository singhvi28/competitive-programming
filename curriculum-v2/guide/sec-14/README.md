### 1. Gaussian Elimination

> **Section:** §14 Linear Algebra & Algebraic Graph Theory  
> **Phase:** Phase 7 — Mathematics, Linear Algebra & Polynomials  
> **Contest ROI:** B-tier | **Rating Range:** 1900–2500 | **Frequency:** Occasional  
> **Prerequisites:** Math, Matrices  

---

#### 1. Contest Payoff & Why It Matters

- Contest ROI: S-tier
- Frequency: Common in Div1 / ICPC
- Typical CF/ICPC rating range: 1800–2400
- Prerequisites: Linear Algebra, Row Operations, Modulo Arithmetic, Bitset
- Tradeoff: Solves systems of $N$ linear equations over $\mathbb{R}$, $\mathbb{Z}_p$, or $\mathbb{F}_2$ (XOR basis) in $\mathcal{O}(N^3)$ or $\mathcal{O}(N^3 / 64)$.

---

#### 2. Theoretical Deep-Dive & Mathematical Mechanics

##### Overview

Linear Algebra and Algebraic Graph Theory model vector spaces, linear dependencies, and spanning tree enumerations: Gaussian Elimination over $\mathbb{R}$ and $\mathbb{F}_2$, Linear/XOR Basis, Matrix Exponentiation, Matrix Tree Theorem, and BEST Theorem.

##### Fundamental Theorems & Invariants

- **XOR Linear Basis Invariant:** An $\mathbb{F}_2$ linear basis of a set of integers contains at most $D$ linearly independent vectors (where $D$ is the bitwidth, e.g. $D=60$). Can determine in $\mathcal{O}(D)$ whether any $x$ is representable and find the maximum possible subset XOR.
- **Matrix Tree Theorem (Kirchhoff):** The number of spanning trees in a graph $G$ equals any cofactor (determinant of $(N-1) \times (N-1)$ submatrix) of the Laplacian Matrix $L = D - A$, where $D$ is the diagonal degree matrix and $A$ is the adjacency matrix.
- **BEST Theorem:** In an Eulerian directed graph with in-degree sequence $d_v$, the number of Eulerian circuits starting at $v$ equals $t_v(G) \cdot \prod_{u \in V} (d_u - 1)!$, where $t_v(G)$ is the number of directed spanning trees rooted into $v$.

##### Algorithmic Execution Blueprint

1. **XOR Basis Insertion:** For value $x$, iterate $i$ from $D-1$ down to 0: if $x$ has bit $i$ set: if basis $basis[i] == 0$, set $basis[i] = x$ and return; else $x \leftarrow x \oplus basis[i]$.
2. **Gaussian Elimination:** Transform matrix $A$ to row echelon form using partial pivoting. Compute determinant as the product of diagonal pivots multiplied by $(-1)^{\text{swaps}}$.

##### Closed-Form Invariant Equations

$$L_{u,v} = \begin{cases} \deg(u) & u = v \\ -w(u, v) & u \neq v \end{cases}, \quad \tau(G) = \det(L_{1..N-1, 1..N-1})$$

##### Structural Edge Cases & Assumptions

- Gaussian elimination over floating points must select the pivot with the maximum absolute value to minimize catastrophic numerical cancellation.
- In XOR basis, $2^{\text{size}}$ distinct subset XOR sums are achievable, and each distinct achievable sum is generated by exactly $2^{N - \text{size}}$ subsets.
- BEST theorem applies only to graphs where every vertex has $\text{in-degree} = \text{out-degree}$ and all edges lie in a single connected component.

---

#### 3. Core Intuition & Problem Framing

Gaussian Elimination transforms an augmented matrix $[A | B]$ into Reduced Row Echelon Form (RREF) using elementary row operations (swapping rows, scaling a row, adding a scaled row to another). Over the real numbers $\mathbb{R}$, partial pivoting (swapping with the maximum absolute entry) prevents numerical instability. Over finite field $\mathbb{Z}_p$, scaling multiplies by the modular inverse. Over $\mathbb{F}_2$ (XOR linear basis), row operations become bitwise XOR, accelerated by 64x using `std::bitset`!

---

#### 4. Proof Sketches & Recurrences

A system of $N$ linear equations with $M$ variables has: 1) Exactly 1 unique solution if rank equals $M$ and no contradictory row $[0 \dots 0 | c]$ ($c \ne 0$) exists. 2) Infinitely many solutions ($p^{M - \text{rank}}$) if consistent and $\text{rank} < M$. 3) 0 solutions if a contradictory row exists. Over $\mathbb{F}_2$, Gaussian elimination computes the basis of the vector space; each basis vector has a unique most significant bit (pivot bit).

---

#### 5. Contest-Ready Implementation Templates

##### C++17 Template

```cpp
// Gaussian Elimination modulo P (Z_p) and XOR Basis (F_2)
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// XOR Basis over F_2 (Bitset optimization)
struct XorBasis {
    ll basis[64] = {0};
    bool insert(ll mask) {
        for (int i = 62; i >= 0; --i) {
            if (!(mask & (1LL << i))) continue;
            if (!basis[i]) { basis[i] = mask; return true; }
            mask ^= basis[i];
        }
        return false;
    }
    ll get_max() {
        ll res = 0;
        for (int i = 62; i >= 0; --i)
            if ((res ^ basis[i]) > res) res ^= basis[i];
        return res;
    }
};
```

---

#### 6. Recognition Trigger Signals & Heuristics

- Find a subset of numbers that achieves the maximum possible bitwise XOR sum (XOR Basis).
- Count number of subsets whose XOR sum equals $0$ ($2^{N - \text{rank}}$).
- Expected number of steps to reach target in a Markov chain on a graph (system of linear equations).
- Nim-game variants and linear switch puzzles (Lights Out puzzle on graphs).

---

#### 7. Contest WA / TLE / RE Traps

- Floating point precision: without partial pivoting, dividing by tiny pivots ($10^{-12}$) leads to catastrophic cancellation; always pick pivot with largest $|a_{i, j}|$.
- Modular inverse: in $\mathbb{Z}_p$, attempting to divide when $\gcd(pivot, p) \ne 1$ (if $p$ is not prime, requires Euclidean elimination).
- Unchecked contradiction: failing to check if a row with all zeros on the LHS has a non-zero RHS (inconsistent system).
- Shift overflow: using `1 << i` instead of `1LL << i` on 64-bit masks.

---

#### 3. Core Intuition & Problem Framing

The determinant $\det(A)$ of an $N \times N$ matrix measures the scaling factor of the $N$-dimensional volume under linear transformation $A$. In competitive programming, determinants are computed via Gaussian elimination: adding a multiple of one row to another preserves the determinant, while swapping two rows multiplies the determinant by $-1$. Once transformed into an upper triangular matrix, the determinant is simply the product of the diagonal elements: $\det(A) = \prod_{i=1}^N A_{i, i}$.

---

#### 4. Proof Sketches & Recurrences

By Leibniz formula, $\det(A) = \sum_{\sigma \in S_n} \text{sgn}(\sigma) \prod_{i=1}^N A_{i, \sigma(i)}$. For an upper triangular matrix $U$ where $U_{i, j} = 0$ for $i > j$, the only permutation with non-zero product is the identity permutation $\sigma = \text{id}$, so $\det(U) = \prod_{i=1}^N U_{i, i}$. If a pivot cannot be found (a column has only zeros below the diagonal), $\text{rank}(A) < N$ and $\det(A) = 0$.

#### 5. Contest-Ready Implementation Templates

##### C++17 Template

```cpp
// Matrix Determinant modulo Prime P in O(N^3)
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll power(ll b, ll e, ll mod) {
    ll res = 1; b %= mod;
    while (e > 0) { if (e & 1) res = (__int128)res * b % mod; b = (__int128)b * b % mod; e >>= 1; }
    return res;
}
ll mod_inv(ll a, ll m) { return power(a, m - 2, m); }

ll determinant(int n, vector<vector<ll>> a, ll mod) {
    ll det = 1;
    for (int i = 0; i < n; ++i) {
        int pivot = i;
        while (pivot < n && a[pivot][i] == 0) pivot++;
        if (pivot == n) return 0; // Rank < N
        if (pivot != i) {
            swap(a[i], a[pivot]);
            det = (mod - det) % mod; // Row swap flips sign
        }
        det = (det * a[i][i]) % mod;
        ll inv = mod_inv(a[i][i], mod);
        for (int row = i + 1; row < n; ++row) {
            if (a[row][i] == 0) continue;
            ll factor = (a[row][i] * inv) % mod;
            for (int col = i; col < n; ++col) {
                a[row][col] = (a[row][col] - factor * a[i][col]) % mod;
                if (a[row][col] < 0) a[row][col] += mod;
            }
        }
    }
    return det;
}
```

#### 7. Contest WA / TLE / RE Traps

- Row swap sign: forgetting to flip the sign of `det = -det` when swapping two rows.
- Modulo is composite: when the modulo $M$ is not prime, modular inverse does not exist; must use Euclidean remainder elimination (like finding GCD between rows).
- Negative modulo results in C++: `(-5) % 10 = -5`; always write `(x % mod + mod) % mod`.
- Modifying the original matrix by reference when the caller expects it preserved.

### 3. Kirchhoff's Matrix Tree Theorem

> **Section:** §14 Linear Algebra & Algebraic Graph Theory  
> **Phase:** Phase 7 — Mathematics, Linear Algebra & Polynomials

#### 1. Contest Payoff & Why It Matters

- Frequency: Iconic ICPC / Div1 Hard

#### 2. Theoretical Deep-Dive & Mathematical Mechanics

---

#### 3. Core Intuition & Problem Framing

Kirchhoff's Matrix Tree Theorem states that the number of spanning trees in any undirected graph $G = (V, E)$ is equal to any cofactor of its Laplacian matrix $L = D - A$, where $D$ is the degree diagonal matrix ($D_{i, i} = \deg(i)$) and $A$ is the adjacency matrix ($A_{i, j} = \text{number of edges between } i \text{ and } j$). A cofactor is obtained by deleting row $k$ and column $k$ from $L$ and calculating the determinant of the resulting $(V - 1) \times (V - 1)$ matrix! For directed graphs, replacing in-degrees or out-degrees counts directed rooted spanning trees (arborescences).

---

#### 4. Proof Sketches & Recurrences

Let $B$ be the $V \times E$ signed incidence matrix of $G$. The Laplacian matrix is $L = B B^T$. By the Cauchy-Binet formula, $\det(L^{(k, k)}) = \sum_{S \subseteq E, |S| = V - 1} \det(B_S^{(k)})^2$. A submatrix $B_S^{(k)}$ has non-zero determinant (specifically $\pm 1$) if and only if the edge subset $S$ forms a spanning tree of $G$. Thus, the sum counts exactly the number of spanning trees.

---

#### 5. Contest-Ready Implementation Templates

##### C++17 Template

```cpp
// Kirchhoff's Matrix Tree Theorem: Spanning Trees modulo P in O(V^3)
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll count_spanning_trees(int n, const vector<pair<int, int>>& edges, ll mod) {
    if (n == 1) return 1;
    vector<vector<ll>> L(n, vector<ll>(n, 0));
    for (auto& [u, v] : edges) {
        // 0-indexed: u, v in [0, n-1]
        L[u][u] = (L[u][u] + 1) % mod;
        L[v][v] = (L[v][v] + 1) % mod;
        L[u][v] = (L[u][v] - 1 + mod) % mod;
        L[v][u] = (L[v][u] - 1 + mod) % mod;
    }
    // Delete row 0 and col 0: construct (n-1) x (n-1) submatrix
    vector<vector<ll>> sub(n - 1, vector<ll>(n - 1));
    for (int i = 1; i < n; ++i)
        for (int j = 1; j < n; ++j)
            sub[i - 1][j - 1] = L[i][j];
    // ... (compute determinant of sub using Gaussian elimination) ...
    return 0; // returns det(sub)
}
```

#### 6. Recognition Trigger Signals & Heuristics

- Problem asks for the number of spanning trees in an arbitrary multigraph.
- Sum of product of edge weights over all spanning trees (Laplacian entry $L_{u, v} = -w(u, v)$, $L_{u, u} = \sum w(u, v)$).
- Counting directed rooted spanning trees (arborescences) rooted at vertex $R$.
- Generating all spanning trees or calculating effective resistance in electrical networks.

---

#### 7. Contest WA / TLE / RE Traps

- Forgetting to delete row $k$ and column $k$: the full $V \times V$ Laplacian matrix has row sums equal to 0, so its full determinant is ALWAYS 0! You must delete one row and column.
- Directed graphs: in-degree vs out-degree confusion. For trees directed towards the root, diagonal entries must be out-degrees; for trees directed away from the root, diagonal entries must be in-degrees.
- Self-loops: self-loops do NOT contribute to spanning trees and must NOT be added to degree counts or adjacency matrices.
- Multigraphs: multiple edges between the same pair of nodes additively increment both the degree diagonal and the adjacency entries.

#### 3. Core Intuition & Problem Framing

The BEST Theorem (named after de Bruijn, van Aardenne-Ehrenfest, Smith, and Tutte) provides an exact closed-form formula for the number of Eulerian circuits in a connected directed Eulerian graph. In any Eulerian graph, every vertex has $\text{in-deg}(v) = \text{out-deg}(v) = d_v$. The BEST theorem states that the number of Eulerian circuits starting at edge $e = (u, v)$ is: $\text{ec}(G) = t_r(G) \prod_{v \in V} (d_v - 1)!$, where $t_r(G)$ is the number of directed spanning trees (arborescences) rooted at an arbitrary vertex $r$ (computed via Kirchhoff's Matrix Tree Theorem in $\mathcal{O}(V^3)$)!

---

#### 4. Proof Sketches & Recurrences

In an Eulerian graph, every Eulerian circuit decomposes into: 1) For each vertex $v$, an ordering of its outgoing edges, where the last outgoing edge from $v$ must belong to an arborescence directed towards a fixed sink $r$ (ensuring no premature deadlocks). There are $t_r(G)$ such arborescences. 2) For each vertex $v$, the remaining $d_v - 1$ outgoing edges can be exited in any of the $(d_v - 1)!$ relative permutations. Multiplying these independent choices together yields $t_r(G) \prod_{v} (d_v - 1)!$.

#### 5. Contest-Ready Implementation Templates

##### C++17 Template

```cpp
// BEST Theorem: Count Eulerian Circuits in Directed Graph
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// Returns number of Eulerian circuits modulo mod
ll count_eulerian_circuits(int n, const vector<pair<int, int>>& edges, ll mod) {
    vector<int> in_deg(n, 0), out_deg(n, 0);
    for (auto& [u, v] : edges) { out_deg[u]++; in_deg[v]++; }
    for (int i = 0; i < n; ++i) if (in_deg[i] != out_deg[i]) return 0;
    // 1. Compute arborescences t_r rooted at 0 via directed Kirchhoff
    ll t_r = 1; // ... det of Laplacian with out_deg on diagonal ...
    // 2. Factorial product prod (deg[v] - 1)!
    ll ans = t_r;
    for (int i = 0; i < n; ++i) {
        if (out_deg[i] == 0) continue;
        ll fact = 1;
        for (int f = 1; f <= out_deg[i] - 1; ++f) fact = (fact * f) % mod;
        ans = (ans * fact) % mod;
    }
    return ans;
}
```

#### 7. Contest WA / TLE / RE Traps

- Graph is not Eulerian: if $\text{in-deg}(u) \ne \text{out-deg}(u)$ for even one vertex with non-zero degree, answer is strictly 0.
- Isolated vertices: vertices with degree 0 do not break Eulerian property of connected components but must be excluded from $(d_v - 1)!$ products.
- Directed Laplacian setup: diagonal must be $\text{out-deg}(v)$, and off-diagonal must be $-A_{u, v}$.
- Forgetting that undirected Eulerian graphs do NOT satisfy the BEST theorem directly (undirected Eulerian circuit counting is #P-complete!).

#### 2. Theoretical Deep-Dive & Mathematical Mechanics

##### Overview

Linear Algebra and Algebraic Graph Theory model vector spaces, linear dependencies, and spanning tree enumerations: Gaussian Elimination over $\mathbb{R}$ and $\mathbb{F}_2$, Linear/XOR Basis, Matrix Exponentiation, Matrix Tree Theorem, and BEST Theorem.

##### Fundamental Theorems & Invariants

- **XOR Linear Basis Invariant:** An $\mathbb{F}_2$ linear basis of a set of integers contains at most $D$ linearly independent vectors (where $D$ is the bitwidth, e.g. $D=60$). Can determine in $\mathcal{O}(D)$ whether any $x$ is representable and find the maximum possible subset XOR.
- **Matrix Tree Theorem (Kirchhoff):** The number of spanning trees in a graph $G$ equals any cofactor (determinant of $(N-1) \times (N-1)$ submatrix) of the Laplacian Matrix $L = D - A$, where $D$ is the diagonal degree matrix and $A$ is the adjacency matrix.
- **BEST Theorem:** In an Eulerian directed graph with in-degree sequence $d_v$, the number of Eulerian circuits starting at $v$ equals $t_v(G) \cdot \prod_{u \in V} (d_u - 1)!$, where $t_v(G)$ is the number of directed spanning trees rooted into $v$.

##### Algorithmic Execution Blueprint

1. **XOR Basis Insertion:** For value $x$, iterate $i$ from $D-1$ down to 0: if $x$ has bit $i$ set: if basis $basis[i] == 0$, set $basis[i] = x$ and return; else $x \leftarrow x \oplus basis[i]$.
2. **Gaussian Elimination:** Transform matrix $A$ to row echelon form using partial pivoting. Compute determinant as the product of diagonal pivots multiplied by $(-1)^{\text{swaps}}$.

##### Closed-Form Invariant Equations

$$L_{u,v} = \begin{cases} \deg(u) & u = v \\ -w(u, v) & u \neq v \end{cases}, \quad \tau(G) = \det(L_{1..N-1, 1..N-1})$$

##### Structural Edge Cases & Assumptions

- Gaussian elimination over floating points must select the pivot with the maximum absolute value to minimize catastrophic numerical cancellation.
- In XOR basis, $2^{\text{size}}$ distinct subset XOR sums are achievable, and each distinct achievable sum is generated by exactly $2^{N - \text{size}}$ subsets.
- BEST theorem applies only to graphs where every vertex has $\text{in-degree} = \text{out-degree}$ and all edges lie in a single connected component.

---

#### 3. Core Intuition & Problem Framing

If you have a sequence of numbers and you suspect they follow a linear recurrence (like Fibonacci), Berlekamp-Massey finds the **shortest** linear recurrence relation that generates the sequence in $O(N^2)$ time. You can generate the first $2K$ terms of a sequence via brute force DP, feed it to Berlekamp-Massey to get the recurrence of size $K$, and then use polynomial multiplication (or matrix expo) to find the $N$-th term in $O(K \log K \log N)$ or $O(K^3 \log N)$.

---

#### 4. Proof Sketches & Recurrences

Berlekamp-Massey iteratively finds the shortest linear feedback shift register (LFSR) generating the sequence prefix. If current recurrence fails on term $a_k$ by discrepancy $\Delta \ne 0$, the recurrence is updated using the recurrence from an earlier iteration $m$ scaled by $\Delta \cdot \Delta_{old}^{-1} \cdot x^{k - m}$. Bostan-Mori uses generating function $A(x) = P(x) / Q(x)$: multiplying numerator and denominator by $Q(-x)$ separates even and odd powers, halving $N$ in each step: $A(x) = \frac{P(x) Q(-x)}{Q(x) Q(-x)}$.

#### 5. Contest-Ready Implementation Templates

##### C++17 Template

```cpp
#include <bits/stdc++.h>
using namespace std;

// Modulo inverse helper
long long power(long long base, long long exp, long long mod) { ... }

vector<long long> berlekamp_massey(const vector<long long>& s, long long mod) {
    vector<long long> C = {1}, B = {1};
    int L = 0;
    long long m = 1, b = 1;
    for (int i = 0; i < s.size(); ++i) {
        long long d = 0;
        for (int j = 0; j <= L; ++j) 
            d = (d + C[j] * s[i - j]) % mod;
        
        if (d == 0) {
            m++;
        } else {
            vector<long long> T = C;
            long long c = (mod - d * power(b, mod - 2, mod) % mod) % mod;
            while (C.size() <= B.size() + m) C.push_back(0);
            for (int j = 0; j < B.size(); ++j)
                C[j + m] = (C[j + m] + c * B[j]) % mod;
            if (2 * L <= i) {
                L = i + 1 - L;
                B = T;
                b = d;
                m = 1;
            } else {
                m++;
            }
        }
    }
    C.resize(L + 1); // C[0] is 1, recurrence coefficients are -C[1], -C[2]...
    return C;
}
```

#### 7. Contest WA / TLE / RE Traps

- Feeding too few initial terms: Berlekamp-Massey requires at least $2d$ terms to guarantee convergence to the unique minimal recurrence of degree $d$.
- Sign convention: make sure whether the returned recurrence is $a_n = \sum c_i a_{n-i}$ or the characteristic polynomial $P(x) = 0$.
- Composite modulus: standard Berlekamp-Massey requires division by discrepancies in a finite field $\mathbb{Z}_p$; $P$ must be prime (e.g. 998244353).
- Initial sequence terms containing leading zeros or irregular prefix before the recurrence stabilizes.
