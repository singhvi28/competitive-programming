## 2. Theoretical Deep-Dive & Mathematical Mechanics

### Overview

Linear Algebra and Algebraic Graph Theory model vector spaces, linear dependencies, and spanning tree enumerations: Gaussian Elimination over $\mathbb{R}$ and $\mathbb{F}_2$, Linear/XOR Basis, Matrix Exponentiation, Matrix Tree Theorem, and BEST Theorem.

### Fundamental Theorems & Invariants

- **XOR Linear Basis Invariant:** An $\mathbb{F}_2$ linear basis of a set of integers contains at most $D$ linearly independent vectors (where $D$ is the bitwidth, e.g. $D=60$). Can determine in $\mathcal{O}(D)$ whether any $x$ is representable and find the maximum possible subset XOR.
- **Matrix Tree Theorem (Kirchhoff):** The number of spanning trees in a graph $G$ equals any cofactor (determinant of $(N-1) \times (N-1)$ submatrix) of the Laplacian Matrix $L = D - A$, where $D$ is the diagonal degree matrix and $A$ is the adjacency matrix.
- **BEST Theorem:** In an Eulerian directed graph with in-degree sequence $d_v$, the number of Eulerian circuits starting at $v$ equals $t_v(G) \cdot \prod_{u \in V} (d_u - 1)!$, where $t_v(G)$ is the number of directed spanning trees rooted into $v$.

### Algorithmic Execution Blueprint

1. **XOR Basis Insertion:** For value $x$, iterate $i$ from $D-1$ down to 0: if $x$ has bit $i$ set: if basis $basis[i] == 0$, set $basis[i] = x$ and return; else $x \leftarrow x \oplus basis[i]$.
2. **Gaussian Elimination:** Transform matrix $A$ to row echelon form using partial pivoting. Compute determinant as the product of diagonal pivots multiplied by $(-1)^{\text{swaps}}$.

### Closed-Form Invariant Equations

$$L_{u,v} = \begin{cases} \deg(u) & u = v \\ -w(u, v) & u \neq v \end{cases}, \quad \tau(G) = \det(L_{1..N-1, 1..N-1})$$

### Structural Edge Cases & Assumptions

- Gaussian elimination over floating points must select the pivot with the maximum absolute value to minimize catastrophic numerical cancellation.
- In XOR basis, $2^{\text{size}}$ distinct subset XOR sums are achievable, and each distinct achievable sum is generated by exactly $2^{N - \text{size}}$ subsets.
- BEST theorem applies only to graphs where every vertex has $\text{in-degree} = \text{out-degree}$ and all edges lie in a single connected component.

## 3. Core Intuition & Problem Framing

Kirchhoff's Matrix Tree Theorem states that the number of spanning trees in any undirected graph $G = (V, E)$ is equal to any cofactor of its Laplacian matrix $L = D - A$, where $D$ is the degree diagonal matrix ($D_{i, i} = \deg(i)$) and $A$ is the adjacency matrix ($A_{i, j} = \text{number of edges between } i \text{ and } j$). A cofactor is obtained by deleting row $k$ and column $k$ from $L$ and calculating the determinant of the resulting $(V - 1) \times (V - 1)$ matrix! For directed graphs, replacing in-degrees or out-degrees counts directed rooted spanning trees (arborescences).

---

## 4. Proof Sketches & Recurrences

Let $B$ be the $V \times E$ signed incidence matrix of $G$. The Laplacian matrix is $L = B B^T$. By the Cauchy-Binet formula, $\det(L^{(k, k)}) = \sum_{S \subseteq E, |S| = V - 1} \det(B_S^{(k)})^2$. A submatrix $B_S^{(k)}$ has non-zero determinant (specifically $\pm 1$) if and only if the edge subset $S$ forms a spanning tree of $G$. Thus, the sum counts exactly the number of spanning trees.

## 5. Contest-Ready Implementation Templates

### C++17 Template

```cpp
// Kirchhoff's Matrix Tree Theorem: Spanning Trees modulo P in O(V^3)
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll count_spanning_trees(int n, const vector<pair<int, int>>& edges, ll mod) {
    if (n == 1) return 1;
    vector<vector<ll>> L(n, vector<ll>(n, 0));
    for (auto& [u, v] : edges) {
        // 0-indexed: u, v in [0, n-1]
        L[u][u] = (L[u][u] + 1) % mod;
        L[v][v] = (L[v][v] + 1) % mod;
        L[u][v] = (L[u][v] - 1 + mod) % mod;
        L[v][u] = (L[v][u] - 1 + mod) % mod;
    }
    // Delete row 0 and col 0: construct (n-1) x (n-1) submatrix
    vector<vector<ll>> sub(n - 1, vector<ll>(n - 1));
    for (int i = 1; i < n; ++i)
        for (int j = 1; j < n; ++j)
            sub[i - 1][j - 1] = L[i][j];
    // ... (compute determinant of sub using Gaussian elimination) ...
    return 0; // returns det(sub)
}
```

## 6. Recognition Trigger Signals & Heuristics

- Problem asks for the number of spanning trees in an arbitrary multigraph.
- Sum of product of edge weights over all spanning trees (Laplacian entry $L_{u, v} = -w(u, v)$, $L_{u, u} = \sum w(u, v)$).
- Counting directed rooted spanning trees (arborescences) rooted at vertex $R$.
- Generating all spanning trees or calculating effective resistance in electrical networks.

---

## 7. Contest WA / TLE / RE Traps

- Forgetting to delete row $k$ and column $k$: the full $V \times V$ Laplacian matrix has row sums equal to 0, so its full determinant is ALWAYS 0! You must delete one row and column.
- Directed graphs: in-degree vs out-degree confusion. For trees directed towards the root, diagonal entries must be out-degrees; for trees directed away from the root, diagonal entries must be in-degrees.
- Self-loops: self-loops do NOT contribute to spanning trees and must NOT be added to degree counts or adjacency matrices.
- Multigraphs: multiple edges between the same pair of nodes additively increment both the degree diagonal and the adjacency entries.
