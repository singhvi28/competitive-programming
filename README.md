# Codeforces Master Transition Curriculum (1900–2300)

A curated, high-yield interactive training curriculum designed for the **Expert (1600–1899)** to **Candidate Master / Master (1900–2300)** rating transition on Codeforces.

## 🚀 Key Modules
1. **Tree Decompositions, HLD & Subtree Aggregates** (Euler Tour, Sack, Dynamic Heavy Edge, Centroid Decomposition)
2. **Data Structures, Cartesian Trees & Offline Reductions** (Monotonic Stacks, Cartesian DP, Sqrt Decomposition, Lazy SegTrees)
3. **Randomization, Polynomial Hashing & Treaps** (64-bit XOR Hashes, Merkle Tree signatures, Las Vegas derangements)
4. **Dynamic Programming Optimizations** (Fenwick DP, Quotient Splitting, Component Merging, Monotonic Transitions)
5. **Graph Structure, 2-SAT & Connectivity** (Tarjan Bridges, DFS Tree Cycles, 2-SAT Implication Graphs)
6. **Network Flow, Min-Cost Flow & Bipartite Matchings** (Dinic, Hall's Condition, Min-Cut, Min-Cost Assignment)
7. **Computational Geometry (1900–2300)** (Manhattan-Chebyshev rotations, Angular Sweep Line, Pick's Theorem, Vector Cross Products)
8. **Linear Basis, Bitwise Invariants & Number Theory** ($\mathbb{F}_2$ Linear Basis, Bit-Trie D&C, Prefix Invariants)

## ⚡ Interactive Features
- **Dark Mode UI** with Tailwind CSS & Glassmorphism
- **Progress Tracking & Checkboxes** persisted via `localStorage`
- **Instant Live Search & Multi-Filters** (by Rating, Topic, Status)
- **Mathematical Formula Rendering** with KaTeX
- **Interactive 6-Week Structured Study Roadmap**
- **Geometry Reference Cheat Sheet**
- **Progress Export & Import** (JSON)
